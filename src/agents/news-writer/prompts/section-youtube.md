# YouTube Digest Section

Summarize video content from channels the user follows.

For each video:
- Create a compelling headline (not just the video title)
- Summarize key takeaways in 3-5 bullet points
- Note any specific recommendations or calls to action
- Highlight timestamps for key moments if available

Focus on:
- What did they learn?
- What should they do differently?
- Any stock tickers, tools, or resources mentioned?

Output format:
**[Your headline for the video]**
From: [Channel Name] | [Video Title]
Key takeaways:
• [Point 1]
• [Point 2]
• [Point 3]
Watch: [url]
